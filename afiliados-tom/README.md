# Afiliados Tom

Projeto independente (não vinculado ao ServNet, portal ou Limpezas Tom).

Operação de afiliado Hotmart baseada em **tráfego pago** (Google Ads como canal principal)
com funil `Anúncio → Landing Page → Checkout Hotmart` e automação de follow-up
(e-mail + WhatsApp + remarketing).
